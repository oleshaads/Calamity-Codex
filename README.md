# Calamity Codex

Русскоязычный офлайн-справочник и маршрут прохождения Terraria с Calamity Mod в самостоятельном статическом интерфейсе.

Внутри: 30 последовательных квестов с интерактивной картой прогресса, полный каталог из 2573 предметов Calamity Mod 2.2.2, 214 отобранных рекомендаций по экипировке, справочник по боссам, рецепты, биомы, словарь, глобальный поиск, быстрые фильтры и сохраняемый «Рюкзак героя».

## Каталог предметов

Раздел «Предметы» не ограничен короткой подборкой и разделён на два режима:

- **Полный каталог** — 2573 подробные карточки. У каждой есть изображение, внутриигровая механика, блоки «где взять», «зачем нужен» и «когда использовать», ссылка на официальную wiki, поиск по описаниям и рецептам, фильтры и избранное.
- **Маршрут прохождения** — 214 русских рекомендаций, привязанных к главам кодекса. Этот режим сохраняет практический порядок развития и не смешивает ключевую экипировку с тысячами коллекционных и декоративных предметов.

Каталог работает офлайн: 2535 официальных предметных или связанных игровых спрайтов хранятся локально; для 38 внутренних записей без самостоятельной публичной текстуры показана честная стилизованная эмблема категории. Локальные исходники дали 1447 непустых официальных tooltip и 1710 рецептов. Там, где исходный код не позволяет надёжно назвать единственный способ получения или точный шанс, карточка не выдумывает ответ и направляет на актуальную страницу официальной Calamity Mod Wiki.

## Источник и пересборка

Данные генерируются из официального публичного репозитория [`CalamityTeam/CalamityModPublic`](https://github.com/CalamityTeam/CalamityModPublic), срез `1a8cebd27ec5615316b78f71973446b5528d2b78` от 8 августа 2026 года.

Генератор читает:

- `Localization/en-US/Mods.CalamityMod.Items.*.hjson` — названия и tooltip;
- `Items/**/*.cs` — rarity, рецепты и texture override;
- `Items/**/*.png` и связанные `NPCs/` / `Projectiles/` PNG — локальные спрайты;
- `NPCs/**/*.cs` — подтверждённые источники выпадения.

Пересборка индекса и каталога спрайтов:

```bash
node scripts/build-item-catalog.mjs \
  /path/to/CalamityModPublic/Localization/en-US \
  calamity-codex/js/catalog.js \
  calamity-codex/assets/item-sprites
```

Сгенерированный `calamity-codex/js/catalog.js` подключается перед `js/app.js`; текстовый индекс, изображения и все основные страницы не требуют серверного API.

## Запуск

```bash
cd calamity-codex
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080/`. Сайт также работает на любом обычном сервере статических файлов.
