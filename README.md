# Calamity Codex

Интерактивный русскоязычный путеводитель по Terraria + Calamity в атмосферном оформлении, вдохновлённом игрой.

Внутри: 30 последовательных квестов с интерактивной картой прогресса, справочник по предметам и боссам, рецепты, биомы, словарь, глобальный поиск, быстрые фильтры и сохраняемый «Рюкзак героя» для избранных предметов, боссов и крафтов.

У каждого крупного раздела есть собственная кинематографичная панорама, цвет интерфейса и атмосферные эффекты, поэтому переход по Кодексу ощущается как путешествие по разным биомам.

## Локальный запуск

```bash
cd calamity-codex
python3 -m http.server 8000
```

После этого откройте <http://localhost:8000>.

Приложение статическое: сборка и серверная часть не требуются.
