# Calamity Codex

Русскоязычный офлайн-справочник и маршрут прохождения Terraria с Calamity Mod в самостоятельном статическом интерфейсе.

Внутри: 30 последовательных квестов с интерактивной картой прогресса, полный каталог из 2535 подтверждённых предметов Calamity Mod 2.2.2, 214 отобранных рекомендаций по экипировке, справочник по боссам, рецепты, биомы, словарь, глобальный поиск, быстрые фильтры и сохраняемый «Рюкзак героя».

## Каталог предметов

Раздел «Предметы» не ограничен короткой подборкой и разделён на два режима:

- **Полный каталог** — 2535 подробных карточек. У каждой есть подтверждённый игровой спрайт, русское описание, блоки «где взять», «зачем нужен» и «когда использовать», ссылка на официальную wiki, поиск по описаниям и рецептам, фильтры и избранное.
- **Маршрут прохождения** — 214 русских рекомендаций, привязанных к главам кодекса. Этот режим сохраняет практический порядок развития и не смешивает ключевую экипировку с тысячами коллекционных и декоративных предметов.

Каталог работает офлайн: все 2535 карточек используют локальные официальные предметные или связанные игровые спрайты. Ещё 38 localization-only записей без подтверждённого самостоятельного изображения намеренно не публикуются: сайт не маскирует отсутствие текстуры выдуманным артом. Для каждой публичной карточки генератор создаёт оригинальное русское описание по категории и подтверждаемым признакам механики; 1447 английских tooltip сохраняются только как исходные поисковые метаданные и не выводятся читателю. Локальные исходники также дали 1710 рецептов. Если код не позволяет надёжно назвать единственный способ получения или точный шанс, карточка направляет на актуальную страницу официальной Calamity Mod Wiki.

## Дерево крафта

Под полкой «Предметы» есть отдельная интерактивная ветка крафта. Кнопка **«+ Выбрать предмет»** открывает список всех предметов с локально подтверждённым рецептом и фильтр по русскому/игровому имени. После выбора кодекс строит горизонтальное дерево: корень → ингредиенты → их рецепты → базовые ресурсы, с защитой от циклов и глубиной, достаточной для полного каталога.

У каждого узла есть настоящий локальный спрайт, количество, станция крафта и источник. Стрелка раскрывает следующую ветку, а клик по карточке открывает подробную карточку с описанием, где взять, зачем нужен, когда использовать и рецептом. Источники-боссы интерактивны: по имени босса открывается его изображение, место и момент боя, способ призыва, совет, награды и переход к соответствующей главе пути.

## Единый карточный справочник

- **Боссы** — 36 противников в порядке прохождения и 3 группы мини-боссов. Карточки сохраняют поиск, фильтры эпох, избранное, призыв, место, рекомендуемый момент боя, дроп и переход к соответствующей главе. Все 36 основных этапов используют настоящие локальные boss-head, lore- или vanilla-спрайты.
- **Справочник** — пять вкладок с 30 этапами прогрессии, 19 комплектами брони, 37 материалами, 10 постоянными улучшениями и 8 механиками. Поиск учитывает русские и внутриигровые названия, источники и назначение; главы ведут к полному практическому маршруту.
- **Словарь** — все 232 записи с RU/EN-названиями, практическими блоками «Где», «Зачем» и «Крафт», поиском по содержимому и фильтром по 22 типам. Карточка показывает настоящий игровой спрайт, когда у понятия есть однозначный ассет; для 23 абстрактных механик, комплектов или биомов используется только связанный игровой ориентир с видимой подписью о том, что именно показано, а не выдуманная эмблема.

Все три раздела используют тот же лаконичный компонент карточки, что и «Маршрут прохождения», а не отдельный перегруженный интерфейс.

## Источник и пересборка

Данные генерируются из официального публичного репозитория [`CalamityTeam/CalamityModPublic`](https://github.com/CalamityTeam/CalamityModPublic), срез `1a8cebd27ec5615316b78f71973446b5528d2b78` от 8 августа 2026 года.

Генератор читает:

- `Localization/en-US/Mods.CalamityMod.Items.*.hjson` — названия и tooltip;
- `Items/**/*.cs` — rarity, рецепты и texture override;
- `Items/**/*.png` и связанные `NPCs/` / `Projectiles/` PNG — локальные спрайты;
- `NPCs/**/*.cs` — подтверждённые источники выпадения.

Пересборка индекса, каталога спрайтов и источников предметов (NPC-дроп, тайлы, сундуки):

```bash
node scripts/build-npc-sources.mjs /path/to/CalamityModPublic calamity-codex/js/npc-sources.js
```

Пересборка индекса и каталога спрайтов:

```bash
node scripts/build-item-catalog.mjs \
  /path/to/CalamityModPublic/Localization/en-US \
  calamity-codex/js/catalog.js \
  calamity-codex/assets/item-sprites
```

Сгенерированный `calamity-codex/js/catalog.js` подключается перед `js/app.js`; текстовый индекс, изображения и все основные страницы не требуют серверного API.

## Оформление и изображения

Интерфейс оформлен как **внутриигровой HUD Terraria**: левая панель — «инвентарь» со слотами-разделами, каждая карточка — слот инвентаря с настоящим игровым спрайтом, прогресс — шкалы в стиле HP/MP, полоса прокрутки — полоска здоровья босса. Типографика — системные моноширинные шрифты в духе игрового UI, без внешних веб-шрифтов: оформление полностью работает офлайн.

Интерактивные эффекты собраны в коде без единого медиафайла:

- звуковой движок WebAudio (клики слотов, фанфары квеста, «рык» на странице боссов, тумблер в шапке);
- Konami-код `↑ ↑ ↓ ↓ ← → ← → B A` включает секретный «Revengeance Mode» — красная вспышка, огонь в фоне и метка в сайдбаре (сохраняется между визитами);
- всплывающие звёздочки при добавлении в избранное, тряска экрана при входе в бестиарий, CRT-сканлайны на экранах шапок;
- глобальный поиск показывает спрайт-иконку каждого результата и понимает русскую транслитерацию («мурамаса» находит Muramasa).

Шапки разделов используют панорамы `headers/*.webp` как «экраны карты», домашняя страница — сцену `hero.jpg` и эмблему `emblem.png` в окне «ПКД-9000». Сцены биомов — авторские иллюстрации в стилистике Террарии (затонувшее море, сернистое море, астрал, планетойды, бездна, джунгли, святые земли, остров зла); закреплённый checkout `CalamityTeam/CalamityModPublic` (`1a8cebd27ec5615316b78f71973446b5528d2b78`) использовался как источник официальных текстур для предметов/боссов/словаря и как референс. Каждый из 18 биомов использует собственную картинку. Карточки крафтов показывают настоящий игровой спрайт результата и иконки ингредиентов, где они известны. Подробное происхождение всех ассетов — в [`calamity-codex/assets/PROVENANCE.md`](calamity-codex/assets/PROVENANCE.md). Предметы, боссы и словарь всегда показывают настоящие игровые спрайты; сгенерированные заменители предметов в поставке отсутствуют.

Пересборка панорам и официальных сцен:

```bash
./scripts/build-official-art.sh /path/to/CalamityModPublic calamity-codex/assets
```

Без аргумента-пути скрипт пересобирает только панорамы, crest и `emblem.webp` из уже поставляемых фонов.

## Запуск

```bash
python3 scripts/serve.py 8099 calamity-codex
```

Сервер отдаёт все файлы с заголовками `Cache-Control: no-store` — браузер никогда не покажет устаревшую картинку из кэша (полезно после изменения ассетов). По умолчанию порт **8097**, каталог `calamity-codex`.

Либо любой обычный статический сервер:

```bash
cd calamity-codex
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080/`.

Перед публикацией можно повторить автономный аудит количества карточек, локальных спрайтов, русских описаний и происхождения декоративных ассетов:

```bash
node scripts/audit-release.mjs
```

Подробный журнал выполненной переработки, появившихся регрессий, их исправлений и оставшихся ограничений находится в [`WORK_REPORT.md`](WORK_REPORT.md).
