# Calamity Codex

Интерактивный русскоязычный путеводитель по Terraria + Calamity в атмосферном оформлении, вдохновлённом игрой.

Внутри: 30 последовательных квестов с интерактивной картой прогресса, полный офлайн-индекс из 2573 предметов Calamity Mod 2.2.2, 214 подробных рекомендаций по экипировке, справочник по боссам, рецепты, биомы, словарь, глобальный поиск, быстрые фильтры и сохраняемый «Рюкзак героя».

Каталог предметов разделён на два режима: «Полный индекс» для поиска по всему составу мода и «Рекомендации» с русскими пояснениями «где взять / зачем». Названия полного индекса собраны из официального репозитория `CalamityTeam/CalamityModPublic`, хранятся локально и ведут на официальную Calamity Mod Wiki.

У каждого крупного раздела есть собственная кинематографичная панорама, цвет интерфейса и атмосферные эффекты, поэтому переход по Кодексу ощущается как путешествие по разным биомам.

## Локальный запуск

```bash
cd calamity-codex
python3 -m http.server 8000
```

После этого откройте <http://localhost:8000>.

Приложение статическое: сборка и серверная часть не требуются.

## Обновление полного индекса

После получения актуального `CalamityTeam/CalamityModPublic` индекс пересобирается без сторонних пакетов:

```bash
node scripts/build-item-catalog.mjs \
  /path/to/CalamityModPublic/Localization/en-US \
  calamity-codex/js/catalog.js
```

Скрипт исключает отладочные записи, дедуплицирует видимые названия и сохраняет commit источника в `catalog.js`.
