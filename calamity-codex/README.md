# Каламити Кодекс

Локальный спутник по **Terraria + Calamity**: режим новичка (30 квестов с нуля) и сжатый справочник (боссы, крафты, биомы, материалы).

В разделах есть отдельный экран «Дерево крафта»: через кнопку «+» выбирается предмет с рецептом, после чего его ингредиенты раскрываются в горизонтальную карту зависимостей до базовых ресурсов. Клик по любому узлу показывает описание, получение, назначение, рецепт и, если источник — босс, его локальную карточку с изображением и условиями боя.

Полный каталог показывает русские названия всех предметов; оригинальное игровое имя остаётся вторичной подписью. Поиск принимает русские названия, английские имена и русскую транслитерацию.

Данные сверены с [официальной вики](https://calamitymod.wiki.gg/wiki/Guide:Mod_progression) (гайд 2.1.2+). Рецепты в патчах могут чуть отличаться — сверяй стол крафта в игре.

## Запуск

Открой `index.html` в браузере или подними любой статический сервер из этой папки.
