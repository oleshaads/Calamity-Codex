# Каламити Кодекс

Локальный спутник по **Terraria + Calamity**: режим новичка (30 квестов с нуля) и сжатый справочник (боссы, крафты, биомы, материалы). Кодекс устанавливается как PWA и после первого открытия сохраняет основную оболочку и текстовые индексы для работы без сети.

В разделах есть отдельный экран «Дерево крафта»: через кнопку «+» выбирается карточка любого предмета Calamity или ванильной Terraria, после чего его ингредиенты раскрываются в горизонтальную карту зависимостей до базовых ресурсов. Карту можно хватать левой кнопкой мыши или пальцем и перетаскивать в любую сторону без полос прокрутки. У каждого узла обязательно заполнен итоговый блок: «Полный рецепт» для создаваемых предметов или «Получение» для дропа, руды, покупок, рыбалки и наград. Для ванильных некрафтовых предметов конкретный источник дополнительно уточняется онлайн по русской официальной Terraria Wiki и кэшируется для последующего офлайн-просмотра. Перед выводом рецепты очищаются от обратных циклов блоков, стен, платформ, руд и конвертаций материалов, поэтому базовый ресурс никогда не требует сам себя. В индекс добавлены 5087 ванильных предметов и 3502 ванильных рецепта. Клик по любому узлу показывает описание, получение, назначение и рецепт. Все 1895 уникальных ингредиентов имеют локальные изображения; противники, турели, разрушаемые тайлы и сундуки в источниках также выводятся отдельными карточками со спрайтами.

Полный каталог показывает русские названия всех предметов; оригинальное игровое имя остаётся вторичной подписью. Для всех 5073 именованных ванильных записей используются официальные названия Terraria, а не машинная транслитерация; 14 безымянных внутренних ID игры честно остаются служебными. Поиск принимает русские названия, английские имена и русскую транслитерацию, запоминает последние открытые результаты, а ванильные результаты открывают конкретное дерево крафта по прямой ссылке. На телефоне фильтры листаются горизонтально, дерево доступно из нижней панели, а кнопки браузера «назад/вперёд» возвращают к прежнему месту чтения. «Рюкзак героя» умеет экспортировать и импортировать локальный профиль.

Данные сверены с [официальной вики](https://calamitymod.wiki.gg/wiki/Guide:Mod_progression) (гайд 2.1.2+). Рецепты в патчах могут чуть отличаться — сверяй стол крафта в игре.

## Запуск

Из корня репозитория:

```bash
python3 scripts/serve.py 8099 calamity-codex
```

Production-интерфейс загружает один минифицированный JS-бандл и минифицированный CSS. После изменения файлов в `js/` или `css/modern.css` пересобери их командами `npm ci` и `npm run build:runtime`; релизный аудит проверяет SHA-256 исходников и не пропустит устаревший бандл.
